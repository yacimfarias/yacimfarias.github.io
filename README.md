# Yaci Farias — site acadêmico

Site pessoal e acadêmico de Yaci Maria Marcondes Farias.

## Stack

- Astro
- TypeScript
- Markdown/MDX (conteúdo acadêmico estruturado)
- CSS próprio
- GitHub Actions
- GitHub Pages

## Desenvolvimento

```bash
npm install
npm run dev
npm run check
npm run build
```

O site é publicado em `https://yacimfarias.github.io` por GitHub Actions.

## Fontes editoriais

O conteúdo inicial foi preparado a partir do Currículo Lattes fornecido e do registro ORCID de Yaci. A bibliografia e a biografia devem passar por revisão da autora antes da publicação final.
